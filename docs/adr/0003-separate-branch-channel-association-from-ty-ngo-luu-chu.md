# Separate the branch-channel association from Tý Ngọ Lưu Chú

Amlich will not label the fixed twelve two-hour Earthly Branch-to-channel association as “Tý Ngọ Lưu Chú.” Classical Tý Ngọ Lưu Chú is a broader day-and-hour acupuncture-point opening method involving stems, branches, channel assignments, and five-shu/original points; collapsing it into a simple “organ clock” would freeze a misleading name into source IDs, contracts, and user interfaces. The first Traditional Wellness milestone may ship the narrower Twelve-Branch Channel Association as non-clinical cultural context, while the true Tý Ngọ Lưu Chú algorithm and every acupuncture-point output remain deferred pending their own source, safety, and validation milestone. Research evidence is recorded in `.planning/research/LUNAR_HEALTH_RESEARCH.md`.

## Consequences

- Traditional Wellness Context never changes Day Assessment, Hour Ranking, or Direction Assessment.
- The semantic model uses association language rather than physiological flow language.
- Channel associations must not claim peak organ function, diagnose imbalance, recommend acupuncture points, or prescribe prevention or treatment.
- Any later Tý Ngọ Lưu Chú implementation requires a separate policy contract, source ID, golden dataset, and explicit safety review.
