  <action>
Create `crates/amlich-core/src/almanac/golden_loader.rs` with the following structs, all deriving `Debug, Clone, Serialize, Deserialize`:

1. **GoldenDataset** -- top-level container:
   - `metadata: GoldenMetadata`
   - `entries: Vec<GoldenEntry>`

2. **GoldenMetadata** -- dataset provenance:
   - `edition: String` (primary KHCBPPT edition)
   - `secondary_edition: String` (Vietnamese translation)
   - `citation_format: String`
   - `date_range: String` (e.g. "2020-2030")
   - `entry_count: usize`
   - `generated: String` (ISO date)
   - `leap_month_policy: String` (document SRC-03 decision: base-month inheritance)

3. **GoldenEntry** -- one date with all subsystem expected values:
   - Date identification: `solar_date: String`, `solar_day: i32`, `solar_month: i32`, `solar_year: i32`, `lunar_day: i32`, `lunar_month: i32`, `lunar_year: i32`, `is_leap_month: bool`, `jd: i32`
   - Can Chi: `day_canchi: String`, `day_can: String`, `day_chi: String`, `day_chi_index: usize`, `year_can: String`
   - Tiet khi: `tiet_khi: String`
   - Truc: `expected_truc_name: String`, `expected_truc_index: usize`, `expected_truc_quality: String`
   - Day deity: `expected_day_deity_name: String`, `expected_day_deity_classification: String`
   - Xung hop: `expected_luc_xung: String`, `expected_tam_hop: Vec<String>`, `expected_tu_hanh_xung: Vec<String>`
   - Na am: `expected_na_am: String`, `expected_element: String`
   - Than huong: `expected_xuat_hanh: String`, `expected_tai_than: String`, `expected_hy_than: String`
   - Stars: `expected_star_index: usize`, `expected_star_name: String`, `expected_star_quality: String`
   - Taboos: `expected_taboos: Vec<String>` (rule_ids that should fire for this date)
   - Citation: `khcbppt_ref: GoldenCitation`

4. **GoldenCitation** -- per-subsystem KHCBPPT citations:
   - `entry_note: String`
   - `truc: String`
   - `day_deity: String`
   - `taboos: String`
   - `stars: String`
   - `xung_hop: String`
   - `than_huong: String`
   - `na_am: String`

Do NOT add any loader logic (include_str!, load functions) yet -- that is Plan 02. This file defines structs only. Add `use serde::{Serialize, Deserialize};` at the top.

Then update `crates/amlich-core/src/almanac/mod.rs` to add `pub mod golden_loader;` after the existing module declarations.

Verify: `cargo check --package amlich-core` must pass (structs compile).
