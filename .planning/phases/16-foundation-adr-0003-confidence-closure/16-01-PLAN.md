Target additive confidence contract created by this plan:
```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize, Default)]
#[serde(rename_all = "lowercase")]
pub enum GoldenConfidence {
    High,
    #[default]
    Medium,
    Low,
}

pub struct PhiTinhGoldenCase {
    // existing fields unchanged
    #[serde(default)]
    pub confidence: GoldenConfidence,
}
```

`GoldenConfidence::Medium` is the compatibility default for historical JSON that omitted the field. The canonical current dataset must therefore set `"confidence": "high"` explicitly; in particular, `annual-thuong-nguyen-1920` and `annual-trung-nguyen-1960` must not pass merely because of a permissive default. Re-export `GoldenConfidence` from `almanac::fengshui` so the external-crate test can use the typed variant.

Current runtime mismatch to remove: `annual.rs` emits `confidence=medium` when `year < 1984`, and `test_compute_yearly_pre_1984_medium_confidence` locks that obsolete behavior.
