<objective>
Wire the two v1.5 pillars into the semantic-graph builder additively: a `FlyingStar` node (`source_id: huyen-khong` only), a `Ritual` node (`source_id: vn-folk-ritual` only), and append a SECOND provenance entry (`huyen-khong`) to the EXISTING shared `Direction` node so it carries both `khcbppt` and `huyen-khong`. `interaction/direction_merge.rs` is NOT touched.

Purpose: INT-04 requires source-id-disjoint pillar nodes plus a multi-source `Direction` node demonstrating provenance dedup/accumulation. The Direction node is created once by `add_travel_direction_fact`; a second `add_node` with the same id would OVERWRITE it (HashMap insert), so the huyen-khong entry MUST be appended to the same node at construction time.

Output: Three builder edits in `day_snapshot.rs` + a unit test asserting the dual-provenance Direction node and the disjoint pillar source_ids.
</objective>
