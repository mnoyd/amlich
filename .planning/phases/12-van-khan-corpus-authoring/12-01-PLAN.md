Top-level file envelope (each .json file):
```json
{ "$schema_version": "rituals-v1", "entries": [ /* RitualEntry... */ ] }
```

One RitualEntry (required fields unless noted):
```json
{
  "ritual_id": "van-khan-tet-don-gian",          // kebab-case, GLOBALLY UNIQUE across all corpus files
  "title_vi": "Văn Khấn Tết Nguyên Đán (Đơn Giản)",
  "event_keys": [ /* see event-key shapes below */ ],
  "variant": "simple",                            // "simple"|"full"|"buddhist"|"folk"|{"regional":"<area>"}
  "offerings": [ {"name_vi": "Hương", "quantity": "3 nén"} ],   // quantity/name_en/notes optional
  "preparation_steps": [ {"order": 1, "description_vi": "..."} ],
  "invocation_text_vi": "Nam mô a di đà phật! ...",
  "source_id": "vn-folk-ritual",                  // ALWAYS exactly this string (loader asserts it)
  "original_citation": { "title": "...", "publisher": "...", "edition": "...", "page": "14" },  // page REQUIRED by RIT-10
  "confidence": "primary"                         // "primary"|"regional-variant"|"synthesized"
}
```

Optional fields you MAY include but are NOT required: `title_en`, `body_en` (LEAVE OUT — reserved/null
in v1.5), `notes` (array of strings).

Event-key shapes (the `event_keys[]` array — discriminated by `kind`):
```json
{"kind": "holiday_id", "value": "tet-nguyen-dan"}                              // value must be a REAL Holiday.id
{"kind": "lunar_date", "month": 1, "day": 1}                                   // FLAT struct — month/day directly
{"kind": "lunar_date", "month": 5, "day": 5, "leap_month_policy": "canonical_month_only"}
{"kind": "solar_term", "name": "Thanh Minh"}
{"kind": "always"}
```
DO NOT write `{"kind":"lunar_date","match":{...}}` — that nested form FAILS to parse. month/day are flat.
`leap_month_policy` is optional; defaults to `"canonical_month_only"`.

Canonical Holiday ids for THIS plan's files (verified against data/holidays/lunar-festivals.json):
- Tết Nguyên Đán: `"tet-nguyen-dan"` (+ lunar 1/1)
- Tết Nguyên Tiêu / Thượng Nguyên: `"tet-nguyen-tieu"` (+ lunar 1/15)
- Tết Hàn Thực: `"tet-han-thuc"` (+ lunar 3/3)
- Tết Thanh Minh: **NO holiday_id** — Holiday id is None (holidays.rs:177). Use `{"kind":"solar_term","name":"Thanh Minh"}`.
- Lễ Phật Đản: `"phat-dan"` (+ lunar 4/15)
- Tết Đoan Ngọ: `"tet-doan-ngo"` (+ lunar 5/5)
