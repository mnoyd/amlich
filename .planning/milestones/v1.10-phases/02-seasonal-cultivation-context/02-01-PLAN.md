Out of scope (carried to bead `.3` / Phase 03): API DTO + `convert.rs` mirror, TUI widget, desktop TS mirror, `EXPLAIN-01` semantic-graph nodes/edges, the unified Traditional Wellness explanation, and the `DaySnapshot.traditional_wellness` additive field.
