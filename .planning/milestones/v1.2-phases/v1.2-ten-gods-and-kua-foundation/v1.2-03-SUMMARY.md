## Decisions Made

- **Ten Gods Computation**: Compute deterministically from day stem to predefined targets (year stem, self) using get_thap_than
- **Kua Field Behavior**: Remain None for date-only requests since birth context (year, gender) not available in calculate_day_fortune signature
- **Backward Compatibility**: All new fields are Option<T> to ensure existing consumers are unaffected
- **Serialization Stability**: JSON field names use snake_case for deterministic output
- **Future Enhancement**: Note in comments that Kua could be added with new function variant accepting birth context
