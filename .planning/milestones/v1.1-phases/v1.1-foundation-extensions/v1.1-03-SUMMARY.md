# v1.1-03 Summary: Tiết Khí Helper Functions

**Phase:** v1.1-foundation-extensions

**Completion Date:** 2026-03-02

## Objective Completed

Implemented Tiết Khí helper function to calculate signed days from any Julian Day to the nearest Solar Term, enabling Đại Vận (Major Luck) calculations that require birth-to-Tiết Khí distances.

## Implementation Summary

### Task 1: Implement get_days_to_nearest_tiet_khi() function - ✅ COMPLETE
- Added `get_days_to_nearest_tiet_khi(jd: i32) -> i32` function
- Returns signed days difference:
  - 0: Input JD is exactly on a Tiết Khí
  - Negative: Nearest Tiết Khí is before input JD
  - Positive: Nearest Tiết Khí is after input JD
- Uses approximate term spacing (365 / 24 = 15.2 days) for JD calculations
- Searches ±2 year window for robust nearest-term finding
- Handles edge cases: exact match, before only, after only, equidistant
- All 5 new tests pass (9/14 tietkhi tests total)

**Commit:** `feat(v1.1-03): implement get_days_to_nearest_tiet_khi() Tiết Khí helper`

### Task 2: Add comprehensive tests for Tiết Khí helper - ✅ COMPLETE
- Added 5 comprehensive tests:
  1. `test_exact_match_returns_zero()` - JD exactly on term → 0
  2. `test_before_returns_negative()` - Before term → negative (within ±10 days)

  4. `test_equidistant_prefers_after()` - Equidistant → prefers after (within ±10 days)
