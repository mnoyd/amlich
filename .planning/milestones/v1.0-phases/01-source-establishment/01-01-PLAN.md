Investigate whether KHCBPPT contains nap am (納音) tables and create na_am.md with the findings.

**Research steps:**
1. Access ctext.org and navigate to the 本原 (Origin Principles) section of 欽定協紀辨方書 (vols 1-2). Search for 納音 content.
2. Determine whether KHCBPPT contains the full 30-pair nap am lookup table or only discusses nap am principles theoretically.
3. If the 30-pair table is found in KHCBPPT: extract the 30 pairs and compare against the current baseline.json values.
4. If not found: document the gap and confirm that Tam Menh Thong Hoi (三命通會) remains the validated source.

**Fallback access paths** (if ctext.org is inaccessible for specific chapters):
- ctext.org full-text search for "納音" in the 欽定協紀辨方書 index
- archive.org scan of 欽定協紀辨方書·卷一 (06056502.cn)
- 1998 Tap 1 PDF at archive.org/details/hiepkybienphuongthu_1998_t1

**Content to include in na_am.md:**

Section 1 — Source Attribution:
- Whether KHCBPPT contains nap am tables (YES/NO with evidence)
- If YES: the KHCBPPT chapter/section reference using the citation format from EDITION.md
- If NO: explicit statement that Tam Menh Thong Hoi is the validated source
- The SRC-02 decision: source_id should be "khcbppt" or "tam-menh-thong-hoi"

Section 2 — 30 Nap Am Pairs:
- All 30 nap am pairs in a structured markdown table
- Columns: Index (1-30), Can pair (e.g., Giap Ty - At Suu), Nap Am name (Vietnamese), Chinese characters, Element (Ngu Hanh)
- Source column indicating which text each value comes from
- Confidence level per entry

Section 3 — Comparison with baseline.json:
- Side-by-side comparison of the 30 pairs in the reference source vs baseline.json
- Note any discrepancies found
- Note the prior corrections from commit 0f29f3f (pair #20 Kim Bac Kim, pair #23 Dai Dich Tho)

Section 4 — Per-subsystem source attribution (supports golden dataset mixed-source design):
- If KHCBPPT: `na_am_meta.source_id` should be updated to "khcbppt" in Phase 4
- If Tam Menh Thong Hoi: `na_am_meta.source_id` stays "tam-menh-thong-hoi"
- Golden dataset schema note: the golden dataset must support per-subsystem source_id

**Anti-patterns to avoid:**
- Do NOT assume KHCBPPT has nap am tables without reading the text — this is the whole point of SRC-02.
- Do NOT reverse-engineer expected values from baseline.json — extract from the source text.
- If ctext.org is inaccessible for the specific chapter, document this honestly and use the fallback path. Even "could not access chapter X; based on KHCBPPT table of contents, nap am is discussed in 本原" is a valid finding.
