# 01-01 Plan — Najia Table Freeze (bead `amlich-xlag.2.1`)

**Milestone:** v1.11 Tý Ngọ Lưu Chú Point-Opening Context (Tier 1)
**Requirements:** `.planning/milestones/v1.11-REQUIREMENTS.md` (SOURCE-01/02, TABLE-01, BOUND-02 corpus side)
**Research:** `.planning/research/TNLC_POINT_OPENING_RESEARCH.md`
**Decision:** ADR 0004 (full point-opening computation, default surface, disclaimer v2, four gates)

## Goal

Freeze the complete Xu-style 納甲法 table set from a chosen *Zhenjiu Dacheng* edition, publish
it as an `ExternalReviewPending` corpus with per-row evidence and the REVIEWER-PACK for Gates
1–4, and leave zero interpretive freedom for the engine bead (`.2.2`).

## Deliverables

1. `crates/amlich-core/data/ty-ngo-luu-chu/najia-open-points.json` — schema
   `najia_open_points_v1`: metadata (sources, edition note, collation, pinned resolution
   conventions, time basis, safety class, gate dates), disclaimer v2 draft, 10 day-tables ×
   6 rows with verse/figure evidence, the full 120-cell (day stem × hour branch) grid with
   explicit open/closed states, and the 66-entry nomenclature registry (Gate-2 drafts).
2. `crates/amlich-core/tests/najia_open_points_corpus_guard.rs` — data-side CI guard
   (structure counts, independent grid re-derivation, bijection, spillover pins, pending
   reviewer literals, closed-slot evidence, clinical-lexeme boundary). No `src/` changes:
   ADR-0003 keeps `ty-ngo-luu-chu` out of production source until `.2.2`.
3. `REVIEWER-PACK.md` (this directory) — §A source-pinned tables + conventions + collation,
   §B–§E sign-offs for Gates 1–4, §F boundaries, §G history, §H outreach.
4. Research ledger §7 checked off with edition-selection evidence; external-review Active
   Register rows added.

## Method constraints

- Every classical row carries evidence: work, juan, verse/table key, transcription URI
  (freeze edition), cross-reference URI (Xu Feng's *Zhenjiu Daquan*), and
  `PENDING_CLASSICAL_REVIEW` facsimile slot for Gate 1 to fill.
- No row from memory or modern charts: tables are transcribed from the two fetched online
  editions and cross-collated (all variants recorded in the pack §A.2); the 120-cell grid
  is *derived* from those tables by the pinned conventions, deterministically, and the CI
  guard re-derives it independently.
- Vietnamese nomenclature and code glosses are drafts pending Gate 2 (TNLC-DIV-04).
- The 亥→子 day attribution pin (子 block belongs to the upcoming civil date) is disclosed
  in metadata and mirrored in the pack; engine goldens freeze it (TNLC-DIV-03).
