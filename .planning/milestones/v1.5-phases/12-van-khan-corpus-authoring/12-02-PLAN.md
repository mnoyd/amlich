File envelope: `{ "$schema_version": "rituals-v1", "entries": [ /* RitualEntry... */ ] }`

Required RitualEntry fields: ritual_id (kebab-case, GLOBALLY UNIQUE), title_vi, event_keys[], variant,
offerings[], preparation_steps[], invocation_text_vi, source_id ("vn-folk-ritual"),
original_citation {title, page (REQUIRED by RIT-10), publisher?, edition?}, confidence
("primary"|"regional-variant"|"synthesized"). Optional: title_en, notes[]. DO NOT set body_en (reserved/null).

variant: "simple" | "full" | "buddhist" | "folk" | {"regional":"<area>"}

Event-key shapes (discriminated by `kind`):
```json
{"kind": "holiday_id", "value": "vu-lan"}
{"kind": "lunar_date", "month": 7, "day": 15}     // FLAT — month/day directly; NOT nested in "match"
{"kind": "life_event", "event": "nhap_trach"}      // event ∈ schema LifeEventKind enum (snake_case)
{"kind": "always"}
```

LifeEventKind values (snake_case in JSON): `dong_tho`, `nhap_trach`, `khai_truong`, `cuoi`, `gio`, `day_thang`.

Canonical Holiday ids for THIS plan's files (verified against data/holidays/lunar-festivals.json):
- Vu Lan / Rằm tháng Bảy: `"vu-lan"` (+ lunar 7/15)
- Tết Trung Thu: `"tet-trung-thu"` (+ lunar 8/15)
- Tết Trùng Cửu: `"tet-trung-cuu"` (+ lunar 9/9)
- Tết Hạ Nguyên: `"tet-ha-nguyen"` (+ lunar 10/15)
- Ông Công Ông Táo: `"ong-tao"` (+ lunar 12/23)
- Giao Thừa: `"giao-thua"` (+ lunar 12/30)

NOTE: Sóc (Mùng 1) and Vọng (Rằm) generic days have Holiday id None — use LunarDate keys only
(e.g. `{"kind":"lunar_date","month":1,"day":1}` for a Mùng-1 template, `{"day":15}` for Vọng). There
is no month wildcard; author 1-2 representative entries and rely on the Always daily entry for
broad daily coverage. Sóc/Vọng entries stay single-variant (research Q2) — do NOT count them toward RIT-12.
