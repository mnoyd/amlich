## Integration verification

1. Desktop `fetchClassicalSurface` invokes the typed Tauri command, which
   calculates one canonical snapshot and uses the existing immutable I Ching
   and direction enrichment helpers. No UI-side domain computation exists.
2. I Ching casting requires an explicit hour selection. Loading the workspace
   without a selected casting hour returns `iching_cast: None`; directional
   data remains available automatically.
3. `SourceId` retains its JSON string representation, so ritual corpus and
   semantic-graph contracts remain wire-compatible while Rust receives a true
   type boundary.
